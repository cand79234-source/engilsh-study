# English OS · 个人英语学习系统

一个**只属于你的、非商业**的英语学习 OS。核心闭环：**学习 → 输出 → 本地批改 → 错误沉淀 → 自动复习 → 周测 → 发现薄弱项 → 补课 → 再学习**。

> ⚠️ **本系统不接入任何 AI / LLM**，不配置任何 API Key，不调用任何外部生成服务。句子批改、词汇补全全部由**内置本地规则与开放词库数据**完成。无网络也能正常使用。

---

## 为什么从零做，而不是 fork

先研究了三个开源项目：

| 项目 | License | 与本项目关系 |
|------|------|----------|
| [English-IA](https://github.com/ErickCassoli/English-IA) | MIT | **架构参考**：FastAPI + SQLite、SRS、错误分层。 |
| [Google Bespoke](https://github.com/google/bespoke) | Apache 2.0 | **算法参考**：多模态技能复习调度、语境化词汇。 |
| [FreeLingo](https://github.com/ArtCC/freelingo) | AGPL-3.0 | **仅参考**：SM-2 实现与 CEFR 路线图设计，避免 AGPL 传染性。 |

三个项目都没有你要的“阶段 → 主题周 → Day 1-7 + 手动调进度不删历史 + 20词 + 主动回忆复习 + 周测 + 错误银行”这套进度引擎。因此**参考架构与算法，代码从零实现**。

---

## 技术栈

- **后端**：Python 3.11 + FastAPI + SQLite（单文件，无需 Docker）
- **前端**：原生 HTML/JS + CSS，**移动优先**（手机可用），无构建依赖
- **本地纠错**：规则引擎（固定搭配 / 主谓一致 / 时态 / 冠词等），无任何 AI/API
- **内置词库**：本地开放词库（146 个基础词 + 292 条例句 + 187 个搭配，覆盖阶段0日常主题），可后续从 ECDICT(MIT)/Tatoeba(CC-BY) 扩充
- **SRS**：SM-2 + “今日新学也纳入当天复习”
- **部署**：一条命令 `bash run.sh`

## 快速开始

```bash
cd /workspace/english-os
bash run.sh
```

浏览器打开：http://localhost:8000

默认进入：**阶段0 → Week 3 → Day 1**（爱好与休闲）。系统会**自动从内置词库填充**本周 20 词，无需手动填词。

## 界面（极简 3 入口）

底部只有 **3 个**导航，不串通、不跳来跳去：

| 页 | 作用 |
|----|------|
| **📖 学习** | 今天该做什么：本周词汇（按 Day 分组显示，点词看中文/词性/例句/搭配/中译+🔊发音→记住了）+ 造句 10 句 + 本周周测 |
| **🔁 复习** | 主动回忆复习到期内容 |
| **🎯 薄弱项** | 造句错误自动沉淀，按类型（🔴🟡）分级，点开看次数/最近/高频规律/补课建议 |

**调整进度**：点击顶部进度徽章（如 `阶段0 · W3 · D1`），弹出进度弹窗，直接改阶段/主题周/Day，系统自动匹配本周内容，历史全保留。

## 已实现的核心功能

1. **进度自动匹配**：系统预置阶段 0 各主题周内容。调进度到哪周，系统**自动从词库填充该周 20 词**，无需手动填内容。
2. **富文本整周导入**：学习页点「导入本周词」，粘贴整段内容如「第2周｜工作与日常｜120词 + 第N组｜分组名 + 单词—中文 + 可选例句」。系统自动识别**一组=一天**（每天 20 词）、去重、跳过注释说明、把生词回填本地词库，缺例句则自动补语法安全的占位句。
3. **离线发音**：单词、例句、搭配均可点击 🔊 朗读，使用浏览器本地 **Web Speech API**，无需联网、无外部服务。
4. **学词**：点词展开详情（中文、词性、固定搭配、例句、中文翻译），点「记住了」自动加入 SRS。
5. **造句 + 本地批改**：10 句引导（写关于你自己的句子）。本地规则引擎自动找错（如 `go work → go to work`、主谓一致、时态、冠词），并分类。
6. **错误库 / 薄弱项**：造句中的错误自动按类型累计（冠词/介词/时态/主谓一致/单复数/词序/固定搭配/词性/拼写/句型/其他），形成薄弱项。独立「薄弱项」页按 🔴🟡 分级，点开看高频规律 + 本地规则生成的补课建议。
7. **复习**：系统自动把到期内容和新学内容加入当天，采用主动回忆（看词→自己造句→判定）。
8. **周测**：语法测试，≥75% 通过进入下一周。
9. **调整进度不删历史**：点顶部进度徽章改当前阶段/周/Day，历史记录、错误、复习全部保留。
